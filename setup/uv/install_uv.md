# Install uv

Install `uv`
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```
Verify
```bash
$ uv

An extremely fast Python package manager.

Usage: uv [OPTIONS] <COMMAND>

Commands:
  auth       Manage authentication
  run        Run a command or script
  init       Create a new project
...
```
Later on upgrade `uv`
```bash
$ uv self update
```
